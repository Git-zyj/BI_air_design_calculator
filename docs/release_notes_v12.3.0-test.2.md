## 和上一版（v12.3.0-test.1）的区别

**分数算法**

- 航程改成"按区域覆盖"来算：现在要多填一个**「目标距离差」**（目标区域的纵深，挡位 100~600、默认 300），
  近边距离 = 最远目标距离 − 目标距离差；**航程够不到近边的飞机分数直接是 0**（以前短腿飞机会被高估），
  所以排名和帕累托前沿都会变；
- 顺带修掉一个会让部分飞机**被误判成 0 分**的问题：像 MiG-9 这种"航程改装拉满其实够得着"的机型，
  以前会被记 0 分，现在能正常参与比较。

**界面**

- **机型名改用游戏里的简称 + 种类**（例如 `Bf 109 G-14 战斗机`），对着游戏里的装备列表更好认；表格那列仍是完整名字；
- **帕累托图**：点表格里某一行，图上会把那一架圈出来（圆环 + 准星 + 名称）；图的两个轴也可以自己切；
- **② 新增「⇄」**：一键把"所选国家"和"对手国别"对调；
- **右键复制**：标签/按钮右键复制文字；表格某一行右键复制机型名称、机型 key、整行；散点图上对着某个点右键复制名称；
- **右上角状态栏**点开是本次的操作记录（可上下左右滑动、可清空、可导出 log）；
- **配点口径**（分离 / 兼顾）的推荐改成按"结果表里第 1 名的总分数"比较，两边真一样时才写"持平"；
- 整体排版统一（字体档位、配色、字段对齐、行距），① 用途改成单选，最远目标距离的挡位随用途变化。
