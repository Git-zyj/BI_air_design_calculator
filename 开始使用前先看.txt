========================================================
  BI Air Design Calculator —— 飞机选型计算器（BIX 专用）
========================================================

【这是什么】

给《钢铁雄心4》BlackICE 系子模组 BIX 用的飞机选型工具。
它回答一个具体问题：**在给定的年份、国家和用途下，该造哪一型飞机、怎么改装、为什么。**

【本工具对应的模组与版本】—— 很重要，装错版本数值会不对

  对应模组： Blackice HOI IV TEST（黑冰**测试版**）workshop id 1851181613
  模组版本： **12.3.0**（exe 名字里的 v12.3.0 就是这个）
  游戏版本： 1.19.2.0（HOI4 本体版本，仅作参考）
  子模组：   BIX（本工具的数据即从这套组合里抽取）

  exe 文件名里已经标好了版本，例如：
      飞机设计计算器_黑冰测试版v12.3.0.exe
  「测试版」= 上面那个 workshop id；「正式版」是另一套，**数据不通用，别混用 exe**
  （用正式版请到 Release 页面下 v12.1.0.x 那一份）。
  如果游戏里的黑冰版本和文件名上的不一致，说明模组已经更新：请到
      https://github.com/Git-zyj/BI_air_design_calculator/releases
  下载与当前模组版本对应的新版（旧 exe 的数值对不上新版本）。

它会做这些事：
  · 按你选的用途（对空 / 对地 / 对海 / 侦察·运输 / 对空（舰载）/ 对海（舰载））
    和目标距离，给所有可用机型打分排名
  · 自动找出每型飞机的最优改装方案（发动机、副油箱、舱盖、对空火力……）
  · 计算分「纯性能」与「总分数（性能÷造价）」，还有「飞机装配资源加权分」
  · 画出帕累托散点图：一眼看出哪些机型是「无脑更优」、哪些是「便宜的够用之选」
  · 推荐用哪个军工组织（MIO）、选哪条配点路线、搭配哪个方针
  · 把结果导出成 Excel


【怎么用】

1. 双击下载到的那个 exe（名字形如 飞机设计计算器_黑冰测试版v12.3.0.exe）
   —— 不需要安装 Python，也不需要装任何库，数据已经打包在里面。
   （首次启动会稍慢 1~2 秒，属于正常现象）
运行过程中的"操作与计算记录"不用黑窗口看：**点右上角状态栏**就能打开日志小窗
（见下面【右上角状态栏】）。
   万一**双击后窗口根本出不来**（闪退 / 没反应），改用同目录的
   「…_调试版.exe」：它会多开一个黑窗口，报错信息会显示在里面。
   打开后工具会**自动按默认输入先算一遍**，所以第一眼就能看到结果表；
   换了输入再点「计算」即可。

2. 从上到下填输入：
   ① 用途         勾任务类型（六个的区别见下面【六个用途的区别】；
                    **只能选一个** —— 再点另一个会自动切过去，点自己保持不变）
                    「最远目标距离」= 目标区域**远边**到你的机场有多远（默认 900；
                    可选挡位随用途变：舰载到 1500、对海到 3000、其余到 2100）；
                    「目标距离差」= 目标区域的纵深（挡位 100~600，默认 300）。
                    两个一起决定"航程够不够"：近边距离 = 最远目标距离 − 目标距离差；
                    飞机航程不超过近边距离时，它对这个区域**完全够不到，效率记 0**
                    （对应游戏里 Coverage in this region 的 0%）。
                    例：最远 900 / 差值 300 → 近边 600 → 航程 600 及以下的飞机飞不到，
                    航程 750 只能覆盖一半，航程 ≥900 全覆盖。
   ② 年份 + 国家   当前年份决定对手机型；科技年份决定你能造哪些机身（可超前研究）
                    国家/对手都用中文名（苏联、德国……）；两个之间的「⇄ 交换」按钮
                    可以**一键把所选国家和对手国别对调**（省得两边各点一次下拉）
                    下面一行是**对手（AI）的修正**：对手设计商加成（机动/速度）+ 对手联队经验加成。
                    设计商不用手输——工具按模组里的 AI 权重（ai_bonus_weights）自动判定
                    "该国 AI 会用哪家 MIO、点哪些特质"（例如德国 1944 战斗机 = 阿拉多），
                    换对手国别/年份会跟着变；和游戏里对不上就直接改这四个数字
                    （改完即生效），点「恢复 AI 自动值」回到自动判定。
   ③ 前置条件     勾上某组 = 这一组前置全部满足，对应改装/方针/特质即可使用
                    （不勾也能算，只是不会把那个改装算进方案）
   ④ 军工组织      默认已按「满级 + 最佳方针」推荐好，也可自己换组织、改等级
                    （路线与方针会跟着年份/距离/对手/国家精神自动重推——想固定某个
                     方针，请先把其它输入设好，最后再选方针）
                    · 「配点口径」二选一：分离 = 本 MIO 只做设计、生产交给更划算的那家；
                      兼顾 = 同一个 MIO 一条路线同时兼顾设计分与生产折算。
                      右边会给推荐（"比另一种高 x%"，按结果表里第 1 名的总分数比），
                      你没自己选过时**默认就跟着推荐**；偶尔两种口径会落到同一套特质，
                      那时显示"高 <0.01%，两种口径同解"（选哪个都一样）。
                    · 「当前效率上限 / 当前产量加成」是你目前在游戏里堆到的生产数值
                      （默认 100% / 200%）：同一个 +5% 产量，堆在 100 和 200 上值的不一样。
   ⑤ 国家精神      填你拥有的国家精神名，点「预览国家精神总加成」看效果
   ⑥ 总体累计      来源二选一：军工组织+国家精神 / 手动输入修正

3. 点「计算」—— 下方 ⑦ 会列出所有候选机型的排名、分数、推荐改装，
   并画出帕累托散点图（横轴造价、纵轴性能分数，默认设置）。
  表格上方可以按年份/帕累托筛选，点表头可以排序。
  点表格里某一行，**帕累托图上会把这架圈出来**（圆环 + 准星 + "选中 XXX"），
  方便对照它落在散点图的什么位置。

4. 点「导出 Excel」把结果存成表格。
   文件位置：**exe 同目录下的 output\ 文件夹**，文件名带国家/年份/用途，
   例如 output\飞机选型_SOV_1944年_科技1944_对空.xlsx
   （第一次导出会自动创建 output 文件夹）

5. 工具会**记住你上次的输入**（关窗口时自动保存），下次打开直接回到那个状态。
   想回到出厂示例（苏联 / 当前 1941 / 科技 1942），点一下 ⑦ 里的「重置为默认」——**立刻**恢复默认输入
   （同时清掉记忆文件，下次启动也是默认值）。


【怎么看结果】

· 总分数（性能/造价）  —— 综合排名的主要依据，越高越好
· 性能分数            —— 不含造价的绝对性能，越高越好
· 有效造价（IC）      —— 已经算了可靠度带来的事故损耗，越便宜越好
· 飞机装配资源加权分  —— 总分数 ÷ 装配资源，资源紧张时看这个
· 帕累托列打 ★ 的机型 —— 「没有别的机型在性能和造价上同时更好」，
                        也就是值得认真考虑的候选；没打星的一般可以直接排除
· 散点图里越靠「右上方」越好（横轴造价越左越便宜）
· 图上和明细里的机型名用**游戏自己的短名 + 种类**（例如 `Bf 109 G 战斗机`、
  `P-51D “野马” 战斗机`、`“喷火” Mk.XIVe 战斗机`）—— 短名就是游戏装备列表里
  那个简称（本地化 `<装备key>_short`），方便对着游戏核对；表格里那列仍是数据里的全名。
· 选中表格某一行，下方会显示这一行完整的推荐改装（表格格子里放不下长文本）
· 界面上的文字**想复制就右键**：标签/按钮右键「复制这段文字」；表格某行右键可以
  「复制机型名称」「复制机型 key」（数据里的 id，方便在模组文件里搜）、「复制整行」；
  散点图上对着某个点右键也能复制那架的名字。（输入框、日志小窗本来就能选中 Ctrl+C）


【六个用途的区别】—— 最容易混的就是这一条

  对空 / 对地 / 对海        —— 陆基口径。注意「对空」「对海」里**会出现舰载机**，
                                因为舰载机能下舰、在陆基机场一样能用。
  对空（舰载）/ 对海（舰载） —— 只挑**能上舰**的机种（普通机上不了舰）；
                                对手也换成舰载机，并且不计经验加成。
  侦察/运输                 —— 侦察机与运输机；不参与交战，只看自身属性。

  一句话：舰载机能下舰，普通机上不了舰。
  想专门比较舰载机选「（舰载）」，想看陆基机场能用的所有飞机选普通的即可。


【常见问题】

Q: 提示缺少 openpyxl / 导出失败？
A: 正常情况下已经打包在内。若仍报错，把报错截图发到 QQ 群 **299043975**，
   或贴到上面那个 Release 页面的留言区。

Q: 数据和游戏里不一样？
A: 数据是从模组文件里抽取的**固定快照**（刻意如此：保证每次结果可复现）。
   模组更新后数值会变，请到 Release 页面换与当前模组版本对应的新版 exe。

Q: 我能自己加国家/改默认值吗？
A: 可以。exe 同目录若存在 inputs.json，会用里面的值作为初始输入；
   界面上的改动不会写回该文件（想固定默认值就手动编辑它）。

Q: 为什么有些机型不在列表里？
A: 两条规则：① 超出你「飞机科技年份」的机身不会出现（游戏里可以超前研究，
   把科技年份调高就能看到）；② **只列最近 3 个年式**——科技年份 1942 就只算
   1940 / 1941 / 1942 的机型，1936 年的 I-16 那种老货不会再占位置（国家在这一档
   没有新机时，会自动放宽到"最近有飞机的那 3 个年式"）。
   这两条都是刻意设计：更老的机身在同一年份里几乎不可能入选，列出来只会淹没真正的候选。

Q: 对手的机动/速度是怎么来的？和游戏里不一样？
A: 对手 = 该机型的原始数值 ×（1 + 设计商修正）×（1 + 满经验）。
   设计商修正由工具自动判定：读模组的 ai_bonus_weights（AI 挑 MIO 的权重），
   在"满级 + 前提"里挑「加成总和最大」的那家 MIO 和那套特质——这就是 AI 的行为，
   和"战斗力最优"不是一回事（德国 1944 战斗机：算出来 = 阿拉多 机动 +4% / 速度 +1.5%，
  与你游戏内看到的面板一致）。和游戏里对不上时，直接在 ② 里改这四个数字即可。

【界面字体】

Windows 上默认使用「微软雅黑」，标题栏右侧会显示当前实际使用的字体名。


【右上角状态栏】

右上角那行是状态栏，会告诉你"刚刚改了什么、现在算出几行"。
**点它可以打开「操作记录 / 日志」小窗**：里面有本次打开后的所有操作与计算记录，
遇到问题点窗里的「导出 log」，会生成一个 txt（在 exe 同目录的 output 文件夹里）。
首次使用（还没有记住过输入）时，状态栏会一直提醒你**先看这份说明**，点开日志窗后提醒消失。
